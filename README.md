_Проект: Симуляция манипулятора Pick & Place в MuJoCo_

  Цель:
  
Реализация детерминированной симуляции промышленного манипулятора с захватом в среде MuJoCo, выполняющего полный сценарий Pick & Place: подход  к объекту, опускание, захват, перенос, укладка в коробку и возврат в исходное положение.

  Технологии:
  
- C++17
- MuJoCo (C API)
- GLFW
- OpenGL

  Структура проекта
  
_assets/scene.xml_ — MJCF-описание сцены (стол, робот, куб, коробка)
_src/main.cpp_ — инициализация MuJoCo, окно, камера, цикл симуляции
_src/robot_controller.h / .cpp_ — FSM и логика управления манипулятором
_src/kinematics.h / .cpp_ — вспомогательная кинематика
_src/utils.h / .cpp_ — утилиты

  Логика работы манипулятора
  
1. Home — начальное положение между кубом и коробкой.
2. MoveYawToCube — движение по дуге к кубу.
3. LowerToCube — опускание до контакта платформы с кубом.
4. CloseFingers — захват куба пальцами после контакта.
5. LiftWithCube — подъем куба.
6. MoveYawToBox — перенос по дуге к коробке.
7. LowerIntoBox — опускание куба в коробку.
8. OpenFingers — разжим пальцев.
9. LiftEmpty и ReturnHome — возврат в исходное положение.

  Запуск проекта
  
1. Установить MuJoCo и GLFW.
2. Добавить пути include и lib MuJoCo в Visual Studio.
3. Убедиться, что mujoco.dll доступен в PATH или рядом с exe.
4. Установить Working Directory = $(ProjectDir).
5. Запустить проект.

  Итог работы
