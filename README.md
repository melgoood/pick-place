# MuJoCo C++ Pick-and-Place (Visual Studio / Windows)

Этот репозиторий — **полностью рабочий** пример MuJoCo (C API) на C++ под Windows: манипулятор 2R на столе **захватывает куб**, переносит его по дуге **90°** вокруг вертикальной оси основания и кладёт в коробку, затем возвращается в нейтральную позу.

---

## 1) Фиксированные численные параметры (используются во всех файлах проекта)

**Единицы:** метры, радианы, секунды.

### Геометрия сцены
- **Стол:** 0.80 × 0.80 × 0.05 (верхняя плоскость стола на `z=0.0`)
- **Радиус размещения объектов:** `r = 0.25`
- **Куб:** 0.04 × 0.04 × 0.04, центр куба на `z=0.02`, позиция `(x=0.0, y=+0.25)`
- **Коробка (контейнер):**
  - внутреннее окно ~0.10 × 0.10
  - толщина стенок: 0.005
  - высота стенок: 0.07
  - позиция `(x=+0.25, y=0.0)`

### Манипулятор
- **Длина звена 1:** `L1 = r = 0.25`
- **Длина звена 2:** `L2 = r = 0.25`
- **Высота оси joint1 над столом:** `0.18`
- **Компенсация ориентации:** `joint3` управляется так, чтобы `joint1 + joint2 + joint3 ≈ 0` (платформа не вращается по yaw в мире; ось остаётся строго вертикальной)

### Вертикальный подъём (поступательный сустав `lift_z`, ось `-Z`, положительное значение = вниз)
- `lift_up   = 0.00`  → центр платформы `z = 0.18`
- `lift_safe = 0.06`  → центр платформы `z = 0.12`
- `lift_pick = 0.14`  → центр платформы `z = 0.04` (уровень верхней грани куба)
- `lift_place= 0.13`  → центр платформы `z = 0.05` (внутри коробки)

### Захват
- Пальцы — симметричные поступательные суставы, диапазон **0 … 0.03**
- `finger_open   = 0.00` (полностью открыто)
- `finger_closed = 0.03` (полностью закрыто: пальцы сходятся к центру)

### Ограничения суставов
- `joint1`: [-2.967, +2.967] рад (±170°)
- `joint2`: [0.10, 3.05] рад (≈ 5.7° … 174.7°)
- `joint3`: [-π, +π] рад
- `lift_z`: [0, 0.16] м
- пальцы: [0, 0.03] м

### Скорости (в коде — rate limit на целевые значения)
- `joint1/joint2`: 1.6 рад/с
- `joint3`: 2.5 рад/с
- `lift_z`: 0.22 м/с
- пальцы: 0.08 м/с

### Усилие захвата
- Используются **position-actuator** с высоким `kp`:
  - пальцы: `kp = 6000`, `kv = 120`
- Трение пальцы/куб повышено, чтобы куб не проскальзывал при подъёме/переносе.

## 3) Установка MuJoCo и зависимостей (Windows)

### Шаг A — скачай MuJoCo
1. Скачай **MuJoCo 3.4.0** (Windows x86_64) с GitHub Releases `google-deepmind/mujoco` и распакуй, например в:
   ```
   C:\mujoco\mujoco-3.4.0\
   ```

2. Внутри должна быть структура вида:
   ```
   include\
   lib\
   bin\
   ```

### Шаг B — GLFW (обычно уже есть в дистрибутиве MuJoCo)
MuJoCo C-сэмплы используют GLFW. В некоторых установках GLFW уже лежит в `include/GLFW` и `lib/glfw3dll.lib`.

Если у тебя **нет** `include\GLFW\glfw3.h` или `lib\glfw3dll.lib`, то:
- скачай prebuilt GLFW (`glfw-3.x.x.bin.WIN64.zip`),
- скопируй:
  - `include/GLFW` → в `C:\mujoco\mujoco-3.4.0\include\GLFW`
  - `lib-vc2022/glfw3dll.lib` → в `C:\mujoco\mujoco-3.4.0\lib\glfw3dll.lib`
  - `lib-vc2022/glfw3.dll` → в `C:\mujoco\mujoco-3.4.0\bin\glfw3.dll`

## 4) Сборка в Visual Studio 2022 (без CMake)

### 4.1 Создай проект
1. `File -> New -> Project -> Console App (C++)`
2. Назови, например `mujoco_pick_place`
3. Платформа: `x64`
4. Стандарт: C++17

### 4.2 Подключи исходники
- Добавь все файлы из `src/` в проект (Source Files / Header Files)

### 4.3 Настрой пути (Project Properties)
Открой `Project Properties` (правой кнопкой по проекту → Properties):

#### C/C++ → General → Additional Include Directories
Добавь:
- `C:\mujoco\mujoco-3.4.0\include`
- `C:\mujoco\mujoco-3.4.0\include\GLFW`

#### Linker → General → Additional Library Directories
Добавь:
- `C:\mujoco\mujoco-3.4.0\lib`

#### Linker → Input → Additional Dependencies
Добавь:
- `mujoco.lib`
- `glfw3dll.lib`

> Если словишь линковку на OpenGL-символах (редко, но бывает): добавь `opengl32.lib`.

### 4.4 DLL рядом с .exe
Скопируй в папку, где лежит собранный `.exe` (например `...\x64\Debug\`):
- `C:\mujoco\mujoco-3.4.0\bin\mujoco.dll`
- `C:\mujoco\mujoco-3.4.0\bin\glfw3.dll`

### 4.5 ВАЖНО: рабочая директория (чтобы находился assets/scene.xml)
`Project Properties -> Debugging -> Working Directory`:
- поставь: `$(SolutionDir)`

Тогда путь `assets/scene.xml` будет корректно находиться без аргументов командной строки.

## 5) Запуск

- Нажми **Local Windows Debugger**
- Откроется окно MuJoCo, и начнётся автоматический сценарий:
  1) нейтральная поза  
  2) перемещение над кубом (безопасная высота)  
  3) опускание до уровня верхней грани куба  
  4) закрытие пальцев (захват)  
  5) подъём  
  6) перенос по дуге 90°  
  7) опускание в коробку  
  8) открытие пальцев  
  9) подъём и возврат в нейтраль

## 6) Управление камерой
- ЛКМ + drag: вращение
- ПКМ + drag: перемещение
- Колёсико: zoom
- `Backspace`: reset симуляции и контроллера
- `Esc`: выход

## 7) Как это устроено
- `assets/scene.xml` — MJCF: стол, робот, куб (free joint), коробка.
- `robot_controller.*` — конечный автомат и генерация целевых позиций суставов.
- `kinematics.*` — IK/forward для 2R в плоскости XY.
- `main.cpp` — GLFW окно, MuJoCo рендер, шаг симуляции, вызов контроллера.
